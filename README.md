# Vortex3D Modeler v1

Terminal-first C++ 3D modeling core prototype.

Features:
- Command shell
- Basic mesh creation
- Cube generation
- Transform placeholders
- Export-ready architecture

Build:
```
mkdir build
cd build
cmake ..
cmake --build .
```

Run:
```
./vortex3d
```

Architecture targets:
- x86 32-bit
- x86_64 64-bit
- Android NDK later
